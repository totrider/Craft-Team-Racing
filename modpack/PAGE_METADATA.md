## Mod
**Name:** Craft Team Racing
**Summary (one line):** Classic-style kart racing built into the Minecraft world: craft and upgrade karts, build tracks from blocks and nodes, race with power-ups.
**Categories:** Game Mechanics, Transportation, Adventure
**Additional tags:** Karts, Racing, Multiplayer, Create (optional)
**Compatibility:** Minecraft: Java Edition 1.21.1, NeoForge 21.1.x; client and server (required on both)
**License:** GPL-3.0-or-later
**Icon:** `Craft Team Racing mod icon.png`

## Modpack
**Name:** Craft Team Racing
**Summary (one line):** A kart racing modpack: build tracks, craft karts and race your friends, with great performance and shader support.
**Categories:** Multiplayer, Optimization, Kitchen Sink
**Additional tags:** Racing, Building, Create (optional), Quality of Life
**Compatibility:** Minecraft: Java Edition 1.21.1, NeoForge; client and server
